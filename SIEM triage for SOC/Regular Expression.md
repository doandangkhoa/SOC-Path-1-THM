# Metacharacters and repetitions

`\d` : matches a digit.

`\D` : matches a non-digit.

`\w` : matches an alphanumeric character. (note that: underscore `_` character is include in this group).

`\W` : matches an non-alphanumeric character.

`\s` : matches a whitespace character (space, tabs, line breaks).

`\S` : matches everything else (alphanumeric characters and symbols).

`{n}` : repeat exactly n times the preceding character.

`{n, m}` : repeat from n to m times.

`{n, }` : repeat 2 or more times.

`*` : repeat 0 or more times.

`+` : repeat 1 or more times.

# Starts with/ ends with, groups and either/or

`^` - starts with character when it places in the beginning of line.  
`$` - ends with

`( A | B)` : define a group of choice
